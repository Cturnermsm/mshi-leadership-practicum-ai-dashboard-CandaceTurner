1. Project Overview
This project was completed as part of the Master of Science in Health Informatics Leadership Practicum at TruLite Health, an equity‑driven health technology company. The purpose of this practicum was to explore how leaders can use population‑level health indicators to guide equitable decision‑making, strengthen early‑risk identification, and ensure responsible governance of predictive tools.

Using the 2015 BRFSS Diabetes Health Indicators dataset, this project analyzes risk‑factor patterns, identifies potential sources of bias, and proposes leadership strategies that align with TruLite Health’s mission to embed equity into clinical workflows.

2. Technologies Used
Excel (pivot tables, descriptive statistics, simple charts)

GitHub (version control, markdown documentation, portfolio structure)

AI Tools (for insight generation and leadership interpretation)

3. Data Source: 
This project uses a publicly available dataset from the CDC Behavioral Risk Factor Surveillance System (BRFSS), accessed via Kaggle. 
The dataset is fully de-identified and contains no protected health information (PHI). It includes population-level indicators related to diabetes, health behaviors, and access to care. 
Privacy Statement: 
No PHI is included in this repository. All data are public, aggregated, and compliant with HIPAA safe harbor standards. 
The questions that I am asking and working to answer is: How can we reduce bias in the algorithm while also reducing burnout within the leadership team?
How can health system leaders use routinely collected risk-factor data (e.g., BMI, blood pressure, cholesterol, smoking, physical activity) to identify and address inequities in diabetes risk—while ensuring that predictive models do not systematically overlook or misclassify high‑risk patients?

5. Key Skills Demonstrated
Equity‑Centered Data Interpretation: Identifying how risk‑factor patterns relate to disparities in diabetes prevention and care.

Leadership Analysis: Translating descriptive data into actionable strategies for workflow improvement, governance, and community‑aligned prevention.

Data Visualization: Creating pivot tables and charts to communicate findings clearly.

AI‑Assisted Insight Generation: Using AI to support leadership decision‑making and critically evaluating its recommendations.

Technical Documentation: Structuring a GitHub repository with clear markdown files, images, and analysis artifacts.

Health Informatics Competencies: Applying principles of data governance, fairness, and responsible model oversight.
